# template — шаблон нового DSH-плагина

Скеффолд из `dsh-dev-workflow`. Клон этой папки = старт нового плагина за минуту,
по правилам, а не с пустого листа.

## Установка (что делает пользователь плагина)

```bash
cp -r template ~/.dsh/.agent-presets/my-plugin   # Windows: Copy-Item -Recurse
# → новая сессия → выбрать пресет my-plugin
```

Проверка монтирования: старт сессии (ростер пометит сломанную композицию) или
`standingKeyFor('my-plugin')` из агент-сессии с доступом к `agentPresets`.

## Что править (чек-лист автора)

- [ ] `preset.yml` — имя и описание
- [ ] `lib/index.js` — имя плагина, имена тулов (уникальный префикс!), логика
- [ ] `agent.cordis.yml` — id ряда, добавить нужные сервисы-потребители (shell, fs…)
- [ ] self-report: у плагина есть способ отчитаться об ошибке
- [ ] пройден `CHECKLIST.md` из корня репозитория

## Ограничения (готчи)

- Файлы пресета — **host-only**: слоты/кнопки/карточки тут не грузятся.
- Инлайн `js:`-ряды не поддерживаются — только `name: './путь.js'` (относительно папки пресета).
- Сервисные ряды — только за isolate-realm; реестры остаются в хост-композиции.
- Скилы пресета подхватываются через `customSkillDirs` (уже в композиции шаблона).
