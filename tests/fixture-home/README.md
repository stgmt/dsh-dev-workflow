# Fixture: корень скилов для тест-кита

Используется тестом `tests/test-kit.mjs` как `<dshHome>` для провайдера
`dsh-skill-filesystem` (watch отключён).

## Матрица

| Папка | name в шапке | Ожидание |
|---|---|---|
| `dsh-plugin-gotchas/` | dsh-plugin-gotchas | ✅ виден (канон) |
| `test-mini/` | test-mini | ✅ виден |
| `var-d/` | var-d | ✅ виден |
| `var-a/` | dsh-plugin-gotchas | ❌ молча пропущен (папка ≠ name) |
| `var-b/` | dsh-plugin-gotchas | ❌ молча пропущен |
| `var-c/` | gotchas-x | ❌ молча пропущен |

## Почему именно так

Эмпирика: discovery стабильно отдаёт каталог на смеси валидных и несовпадающих
кейсов; на корне с одним-единственным валидным скилом результаты нестабильны
(воспроизведено в зондах, корневая причина в провайдере не найдена). Фикстура
фиксирует работающую конфигурацию И одновременно тестирует правило
«имя папки обязано совпадать с name в шапке».
