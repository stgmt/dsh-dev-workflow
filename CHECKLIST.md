# CHECKLIST — приёмка плагина/пресета

Контрольный список перед словами «готово / работает». Пройди сверху вниз;
любой непройденный пункт — это незаконченная работа, а не мелочь.

## После запуска/апдейта (Фаза 3)

- [ ] `cordis_inspect_self(pluginId, packageId)`: `state` соответствует замыслу
- [ ] `hasHostHalf` / `hasClientHalf` совпадают с задумкой (после update — проверены ОБЕ половины)
- [ ] `runtime.host.handlers` содержит все заявленные RPC-методы
- [ ] `host.error`, `client.error`, `renderFailure` — пусты
- [ ] `Tool.listTools`: тул виден под правильным именем; чужие тулы не вытеснены
- [ ] Дерево слотов: регистрант `dyn/<pluginId>` активен в нужном слоте
- [ ] Видимость глазами: кнопка/карточка реально видна пользователю (и в rail-режиме, и в wide)

## После остановки/удаления (обратимость)

- [ ] stop/update: таймеры, тулы, обработчики, слушатели исчезли вместе с плагином
- [ ] undefine — только если версии больше не нужны; иначе stop

## Гигиена

- [ ] Временные файлы-артефакты удалены (в т.ч. в чужих директориях — fallback-корень!)
- [ ] Упавшие пакеты не правились руками — только новые версии
- [ ] Новый инцидент → обновлён канон скила (фаза + чек-поинт + готча в справочнике)

## Для пресетов (Фаза 5)

- [ ] `standingKeyFor(id)` — монтируется: OK
- [ ] `customSkillDirs` на месте, если в пресете есть скилы
- [ ] Сервис-ряды — за isolate-realm
- [ ] Проверка в НОВОЙ сессии (текущая сессия не видит изменений пресета)
